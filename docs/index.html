Hexal

D&D Hex Crawl Campaign Manager

v1.3.0
Download for macOS (Apple Silicon) macOS (Intel) Windows

Everything you need to run a hex crawl

From terrain painting to encounter tracking, Hexal handles the bookkeeping so you can focus on storytelling.

🗺

Visual Hex Grid

Canvas-rendered hex map with 10 terrain types, LOD zoom system, and smooth pan/zoom navigation.

🏰

Tabletop Markers

Place draggable figurine-style markers for settlements, dungeons, players, and custom tokens on the map.

🌊

Rivers & Roads

Draw hex-edge connections for rivers and roads that render on the grid and affect travel costs.

⚔️

Encounter System

Full encounter editor with creature rosters, rewards, difficulty ratings, outcomes, and reusable templates.

🧙

NPC Directory

Track NPCs with alignment, attitude, faction membership, relationships, and cross-hex references.

📍

Content per Hex

Each hex holds locations, encounters, NPCs, treasures, and clues with resolve tracking.

🎲

Procedural Generation

Generate terrain, encounters, and landmarks from configurable tables with seeded PRNG for reproducibility.

🌍

Region Manager

Define named regions with color borders, hex assignments, descriptions, and discovery status.

⛅

Weather Simulation

Real-time weather radar with pressure systems, isobars, fronts, cloud cover, rain/snow particles, lightning, and ambient audio that shifts with zoom altitude.

📺

Player View

Second window showing a fog-of-war filtered map safe to share on a screen visible to players.

📜

Session Log

Timeline-based session logging with tags, in-game timestamps, and per-hex event tracking.

🖼️

Map Export

Export your map to PNG, JPEG, or PDF with print-ready and player handout presets.

See it in action

Screenshots from a real campaign built in Hexal.

Three-Column Layout

The main editor puts everything at your fingertips: a filterable hex list in the sidebar, the canvas map in the center, and a detail panel on the right showing all content for the selected hex.

Rich Encounter Editor

Build encounters with creature rosters, difficulty ratings, linked NPCs, and detailed rewards. Track outcomes as your campaign unfolds, or create reusable templates for random encounters.

NPC Relationship Network

Every NPC tracks race, class, alignment, attitude, faction membership, and relationships to other NPCs across the map. The NPC Directory gives you a bird's-eye view of your cast of characters.

Procedural Generation

Generate terrain, encounters, and landmarks across your grid using configurable density sliders and terrain tables. A seeded PRNG ensures you can reproduce the same results.

Player View

Open a second window that shows only discovered hexes, with fog of war hiding DM-only content. Perfect for streaming or projecting onto a second screen at the table.

Session Timeline

Log events as they happen during your sessions, tagged by type and linked to specific hexes. Review the full timeline to recall what happened and when.
